# Russian Custom Formats — Dub Priority v2 (TEST)

Тестовая версия набора для Radarr и Sonarr. Предпочтение: **подтверждённая русская аудиодорожка → тип перевода → небольшие бонусы за студии и технологии**. Ветка не влияет на `main`.

## Безопасный выбор аудиодорожки

- `RU - Russian Language` (+10000): язык Russian из данных Servarr.
- `RU - Russian Title or Studio Fallback` (+10000): только при языке, не определённом как Russian, и явном русском аудиомаркере либо тщательно отобранном российском студийном маркере.
- Отдельные `DUB`, `DUBBED` и `DUBBING` **не подтверждают русский язык**. `GERMAN.DUB`, `FRENCH.DUB` и `RUSSIAN.SUBTITLES` не должны проходить языковой порог. Голое слово «дубляж» без указания языка остаётся эвристикой, а не гарантией: важен разбор фактических дорожек.
- Многоязычная студия `Movie Dubbing`, короткие обозначения `RHS`, `DEEP`, `Nota` и аниме-группы не служат самостоятельным подтверждением русского языка.
- Маркеры студий сами по себе **не доказывают тип перевода**. Например, `MVO.MovieDalen` не должен получить категорию Dubbing.

## Баллы

| Тип перевода | Баллы |
|---|---:|
| Явный дубляж | +5000 |
| Профессиональный многоголосый | +4000 |
| Профессиональный двухголосый | +3000 |
| Обычный многоголосый | +2000 |
| Обычный двухголосый | +1000 |
| Одноголосый / авторский (включая AVO) | +500 |

Остальные оценки — в [scores.csv](./scores.csv). Бонусы за студию (+75), источники (+50), известные команды (+50) и технические метки (+10…+30) невелики по отношению к интервалам категорий. Новые правила: **явный официальный/лицензионный дубляж** (+100) и **явный любительский/fandub** (−150). По имени компании официальность нельзя достоверно установить.

**Настройки Quality Profile:** Minimum Custom Format Score = `10000`; Allow Upgrades = on. Для предотвращения преждевременной остановки рекомендовано `Upgrade Until Custom Format Score = 30000` как высокий практический порог, либо значение без ограничивающего cutoff, если его допускает версия приложения. Установленный максимум зависит от того, какие сочетания форматов разрешены в конкретном профиле; настройте его осознанно. После изменения баллов перезапустите переоценку имеющихся релизов.

Импортируйте **только этот набор**, не объединяйте с `Russian-Custom-Formats-2026`. JSON из `Radarr/` — в Radarr, `Sonarr/` — в Sonarr. После импорта назначьте баллы вручную из CSV (импорт JSON сам по себе их в Quality Profile не устанавливает). Для Radarr: Preferred Language = `Any` при использовании языкового Custom Format.

## 4K, Dolby Vision и источники

Качества WEB-DL 2160p / UHD Blu-ray 2160p активируются **в Quality Profile**. При разных уровнях Quality качество может обгонять Custom Format: при жёстком предпочтении дубляжа объедините приемлемые качества в группу и проверьте сортировку в интерактивном поиске.

`UHD - DV without HDR fallback (WEB)` (−20000) — **необязательный штраф совместимости** для явно DV-only WEB-источников. Отключайте или уменьшайте его, если все устройства гарантированно поддерживают DV, или если тегов недостаточно для уверенного вывода. Правило по названию не может подтвердить реальное наличие HDR10 fallback. Встроенный HDR CF больше не использует прежнее неоднозначное DV-условие. `HULU` исключён из этого штрафного формата. Проверяйте MediaInfo перед окончательным выбором.

## Проверки

`node --test tests/*.test.mjs` запускает проверки JSON, синхронизации Radarr/Sonarr, тестовых названий, регрессий ложного русского DUB, начисления баллов и безопасности DV. GitHub Actions запускает их при push/PR. Требуется Node.js 22 или новее.

**Ограничения:** никакие Custom Formats не читают фактический список аудиодорожек до загрузки, поэтому эвристики не гарантируют полный русский дубляж. `DUB` на иностранном языке может получить только бонус категории, но не пройти русский gate самостоятельно; при присутствии русского gate и иностранного DUB в одном названии ошибочные предпочтения остаются возможны без проверки дорожек. Не используйте этот набор для автоматических удалений/перекодирования файлов без ручной верификации.
