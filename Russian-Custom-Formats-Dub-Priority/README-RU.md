# Russian Custom Formats — Dub Priority

Набор для выбора русскоязычных релизов с приоритетом качественной озвучки. Аниме-группы исключены.

## Приоритеты

| Тип перевода | Score |
|---|---:|
| Дубляж / явный DUB | +1000 |
| Профессиональный MVO | +800 |
| Профессиональный DVO | +600 |
| Обычный MVO | +400 |
| Обычный DVO | +200 |
| Одноголосый / авторский | +100 |

MovieDalen, The Kitchen Russia, CineLab SoundMix и ПроДубляж добавлены в студийные признаки дубляжа (+1000). Популярные сериальные/закадровые команды получают +50.

## Русский аудио-gate
- `RU - Russian Language`: Servarr определил язык как Russian.
- `RU - Russian Title or Studio Fallback`: резервный путь — язык не распознан как Russian, но найден явный русский аудиомаркер или известная российская студия.

Рекомендуемый Minimum Custom Format Score: `10000`. Отдельное слово `DUB` также считается русским аудиомаркером — это удобный эвристический признак для названий вроде `Dub + AVO`, но он может ошибочно пропустить дубляж на другом языке. Маркеры только субтитров `RUS SUB` / `Russian Subtitles` не используются как подтверждение русской аудиодорожки.

Рекомендуемый Upgrade Until Custom Format Score: `11000`; Allow Upgrades включить.

## Установка
Импортируйте JSON из `Radarr` в Radarr и из `Sonarr` в Sonarr через `Settings → Custom Formats → Import`. Назначьте оценки из [scores.csv](./scores.csv). В Radarr Preferred Language = `Any`.

## 4K
2160p WEB-DL и UHD Blu-ray включаются отдельно в Quality Profile. Если 2160p стоит выше 1080p, 4K с MVO может опередить 1080p-дубляж: качество и CF score — отдельные уровни приоритета.

## Примечание по Bravo Records
Bravo Records не включён в русский список дубляжа: официальный сайт описывает дубляж иностранных фильмов на грузинский язык, а не на русский. Это защищает профиль от ложного определения грузинской дорожки как русской.

## Ограничения
CF не проверяют фактические аудиодорожки. Язык берётся из метаданных, студия — подсказка. Первые загрузки проверьте в MediaInfo.
