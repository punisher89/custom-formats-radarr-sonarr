# Russian Custom Formats — Dub Priority TEST

**Отдельная тестовая версия. Основная папка `Russian-Custom-Formats-Dub-Priority` не изменена.**

Цель — исправить ложные совпадения и сохранить поддержку заголовка RuTracker вида `Dub + AVO + Original Eng + Sub (Rus, Eng)`.

## Что изменено

1. `RU - Russian Language` требует Language=Russian и исключает явные подписи `Sub (Rus, Eng)`, `Rus Sub`, `Russian Subtitles`.
2. Обычный fallback работает, если язык не распознан как Russian, но есть русский аудиомаркер, известная русская студия или отдельное слово `DUB`. Самостоятельный `RUS` не считается аудио.
3. Формат для `Dub + AVO + Original Eng + Sub (Rus, Eng)` требует DUB или известную русскую студию вместе с русским субтитровым тегом; AVO как условие не используется.
4. Известные подписи French Dub, German Dub, Spanish Dub, Italian Dub и ряд других блокируются в русском fallback. Список иностранных языков не исчерпывающий.
5. Самостоятельный `DEEP` удалён; оставлены только `Studio DEEP` / `DEEP Studio`, чтобы не совпадать с `Deep Space Nine`.
6. Аниме-команды удалены из студийного fallback. Если язык действительно распознан как Russian, языковой формат всё ещё может принять релиз; отдельного аниме-бонуса нет.
7. Убраны неоднозначные короткие алиасы bare `RHS` и `Nota`. Сохранены MovieDalen, ProDyblaj, CineLab SoundMix, The Kitchen Russia и другие более точные названия.
8. HDR, Dolby Vision и HDR10+ получают UHD-бонусы только при наличии `2160p` в названии.
9. Расширены студийные/дубляжные метки: `Movie Dubbing`, `CPI Films`/`CPIG`, `Flarrow Films`, `Videofilm Int`; `Дубляж Ист-Вест` учитывается только как точная подпись дорожки. Для Flarrow явные MVO/DVO/AVO/VO отменяют дубляжный бонус, если отдельный `DUB` не указан.
10. `RU - Dub Source Hint` даёт +50, если в названии одновременно есть явный `DUB` и источник `Кинопоиск HD`, `iTunes`, `Blu-Ray`, `Blu-Ray CEE` или `BD CEE`. Одиночный источник не доказывает наличие русского дубляжа.
11. Все 18 исходных форматов тестового набора настроены на включение метки в переименование; где необходимо, добавлено повторное распознавание собственной метки.
12. Новый 19-й формат `RU - Russian Language Archive` восстанавливает +10000 после переименования: исходный `RU - Russian Language` определяется по языку, а сохранённая метка в имени уже не содержит языковых метаданных. Архивный формат распознаёт только эту метку и сам в имя не добавляется.

## Компромисс одиночного DUB

Отдельное слово `DUB` сохранено по твоей просьбе для RuTracker. Явные French/German/Spanish Dub (в том числе варианты с `+` между словами) блокируются, но неизвестный язык рядом с DUB всё ещё может пройти. Надёжнее всего `RUS DUB`, `DUB RUS`, `RUSSIAN AUDIO` или имя известной российской студии.

## Сохранение Custom Formats при переименовании

В Radarr: **Settings → Media Management → Movie Naming**. В Sonarr: **Settings → Media Management → Episode Naming**.

Добавь именно токен `{Custom Formats}` (без квадратных скобок внутри фигурных) в шаблон имени файла. Не нужно заменять весь свой шаблон: достаточно вставить его в удобное место, например перед блоком качества. Если нужны квадратные скобки вокруг списка форматов, записывай `[{Custom Formats}]`.

Пример для Radarr:

```
{Movie CleanTitle} ({Release Year}) {Custom Formats} {[Quality Full]} {[MediaInfo VideoDynamicRangeType]} {[Mediainfo AudioCodec}{ Mediainfo AudioChannels]}{-Release Group}
```

Токен выводит только те Custom Formats, у которых включено **Include Custom Format when Renaming**. В тестовом наборе это включено для исходных 18 форматов только после применения соответствующих JSON. У `RU - Russian Language Archive` опция выключена намеренно: архивная метка не должна добавляться повторно.

### Как устроено восстановление баллов

- До переименования язык распознаёт `RU - Russian Language` и даёт +10000.
- При переименовании токен сохраняет буквальную метку `RU - Russian Language` в имени файла.
- После переименования Radarr/Sonarr уже не могут вывести язык из одной этой метки. Поэтому `RU - Russian Language Archive` распознаёт её и даёт те же +10000.
- Метки дубляжа, студии, HDR/DV/HDR10+ и аудиоформатов повторно распознаются соответствующими тестовыми правилами.

**Важно:** это сохраняет баллы для новых загрузок, переименованных с этим токеном. Если файл был переименован раньше и исходная метка нигде не сохранилась, восстановить утраченное название студии или дубляжа из одного текущего имени невозможно.

## Оценки

Используй [scores.csv](./scores.csv):
- Minimum Custom Format Score: `10000`
- Upgrade Until Custom Format Score: `11000`
- Allow Upgrades: включено
- Radarr Preferred Language: `Any`

Три русских проходных формата задуманы как альтернативные пути: распознанный язык, обычный fallback и отдельный subtitle-parser bypass. Архивный формат не является дополнительным способом принять новый релиз: он нужен только для уже сохранённой метки.

## Импорт

- Radarr: JSON из `Radarr/`
- Sonarr: JSON из `Sonarr/`
- Баллы: [scores.csv](./scores.csv)

**Не импортируй тестовый и основной наборы одновременно в один профиль.** Создай отдельный тестовый профиль или используй отдельный экземпляр. Основной каталог не удаляй.

## Проверка

1. Импортируй 19 JSON из соответствующей папки в тестовый Radarr/Sonarr.
2. Включи `{Custom Formats}` в шаблоне переименования.
3. На исходном релизе проверь совпавшие форматы и сумму баллов.
4. Переименуй один тестовый файл.
5. Проверь новое имя через Interactive Search / `/api/v3/parse` (Radarr) или соответствующий Parse endpoint Sonarr.
6. Убедись, что вместо `RU - Russian Language` срабатывает `RU - Russian Language Archive`, а общая сумма не меняется. Архивный формат не должен добавлять вторые +10000.

Сценарии тестирования: [TEST-CASES.md](./TEST-CASES.md).

## Ограничения

Custom Formats не прослушивают аудиодорожки и не читают полный текст темы RuTracker. Они анализируют название релиза и данные индексера. После загрузки дорожки проверяй MediaInfo.
